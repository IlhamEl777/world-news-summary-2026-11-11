One tight, source-attributed summary of the world's news of Wednesday 11
November 2026 — the Abu Dhabi prisoner-exchange agreement, the Strait of
Hormuz dispute, the COP31 leaders' summit, the stalled Hegseth
impeachment, Gaza, the Gloucestershire spy arrest, Sudan and the US
boycott of its UN human-rights review — in under 2,000 characters. The
program writes the summary in `summary.txt` to the output as
`entry.txt`, byte for byte, so two runs always agree.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
